# Schuelerverwaltung

### Schwierigkeitsgrad: *

Eine Klasse hat eine feste Anzahl von Schüler /-innen. Für jede Person sollen Noten gespeichert werden (jede / r Schüler / -inn) hat einen Datentype.

1. Legen Sie eine Datenstruktur mit 5 Noten (Ganzzahl 1 bis 6) an. Lassen Sie sich alle Noten ausgeben. 

2. Ermöglichen Sie das Hinzufügen einer neuen Note, auch wenn die ursprüngliche Größe nicht ausreicht.
