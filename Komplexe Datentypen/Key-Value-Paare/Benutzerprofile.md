# Benutzerprofile

### Schwierigkeitsgrad: **

**Aufgaben**
1. Legen Sie eine Map an, die Benutzer-IDs auf Namen abbildet.

2. Erweitern Sie die Werte zu komplexeren Daten (z. B. verschachtelte Struktur mit Name, Alter, E-Mail). Geben Sie alle Daten zu einer ID formatiert aus.

3. Fügen Sie einen neuen Benutzer hinzu.

4. Ändern Sie die E-Mail-Adresse eines beliebigen Benutzers.
