# Produktlager


### Schwierigkeitsgrad: *


Ein kleines Lager verwaltet Produktnamen.


**Aufgaben**
1. Legen Sie eine Liste mit 5 Produktnamen an. Prüfen Sie, ob ein bestimmtes Produkt enthalten ist.

2. Fügen Sie ein neues Produkt hinzu, entfernen ein verkauftes Produkt. 

3. Zählen Sie die aktuelle Anzahl.
