# Einkäufe


### Schwierigkeitsgrad: **


In einem Programm soll der Nutzer die Möglichkeit erhalten, seine Einkäufe selbst-ständig einzugeben. Zu Beginn fragt das Programm, ob ein Produkt gekauft wurde. Falls der Nutzer dies verneint, wird das Programm mit dem Hinweis „Schade, dass Sie nichts gekauft haben.“ beendet. Falls der Nutzer jedoch angibt, ein Produkt gekauft zu haben, wird er nach dem Preis dieses Produkts gefragt. Der eingegebene Preis wird gespeichert und zum Gesamtpreis addiert. Anschließend wird der Nutzer erneut gefragt, ob er ein weiteres Produkt gekauft hat. Dieser Vorgang kann beliebig oft wiederholt werden, sodass mehrere Produkte erfasst und deren Preise aufsummiert werden können. Sobald der Nutzer keine weiteren Produkte mehr ein-geben möchte, wird der Gesamtpreis aller Einkäufe ausgegeben. Je nach Höhe des Gesamtpreises erscheint eine entsprechende Abschlussnachricht:  


- Liegt der Gesamtpreis bei mind. 20,00 €, wird ausgegeben: „Danke, dass Sie einen großen Einkauf getätigt haben!“
- Liegt der Gesamtpreis zwischen 0,01 € und 19,99 €, wird ausgegeben:„Danke, dass Sie einen kleinen Einkauf getätigt haben!“
