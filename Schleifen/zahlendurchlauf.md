# Zahlendurchlauf

### Schwierigkeitsgrad: **

Erstellen Sie ein Programm, das den Benutzer zunächst nach einer Obergrenze fragt. Anschließend sollen alle Zahlen von 0 bis einschließlich dieser Obergrenze mithilfe einer Schleife ausgegeben werden. Für jede Zahl soll das Programm prüfen, ob es sich um eine gerade oder eine ungerade Zahl handelt und eine entsprechende Meldung ausgeben. Zusätzlich soll untersucht werden, ob die Zahl durch 3 teilbar ist. Ist dies der Fall, soll dies ebenfalls angezeigt werden.

Während der Schleife sollen verschiedene Werte mitgezählt und gespeichert werden. Bestimmen Sie die Anzahl der geraden und ungeraden Zahlen sowie die jeweilige Summe aller geraden und aller ungeraden Zahlen. Geben Sie diese Ergebnisse nach Beendigung der Schleife übersichtlich aus.
