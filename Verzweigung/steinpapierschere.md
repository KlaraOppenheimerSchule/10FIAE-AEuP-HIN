# Stein Papier Schere


### Schwiergkeitsgrad: **


Programmiere das Spiel „Schere, Stein, Papier“ für zwei Spieler. Beide Spieler sollen nacheinander ihre Auswahl eingeben. Verwenden Sie dabei die Zahlen 1 für Stein, 2 für Papier und 3 für Schere.


Das Programm soll zunächst prüfen, ob beide Spieler dieselbe Auswahl getroffen haben. In diesem Fall soll die Meldung „Unentschieden“ ausgegeben werden. Haben die Spieler unterschiedliche Eingaben gemacht, soll das Programm anhand der bekannten Spielregeln ermitteln, welcher Spieler gewonnen hat, und eine entsprechende Meldung ausgeben.


Nutze zur Lösung verschachtelte if-else-Anweisungen. Achte darauf, dass alle möglichen Kombinationen der Eingaben korrekt berücksichtigt werden.


**Zusatzaufgabe**: Erweitere das Programm um eine Eingabeprüfung. Werden andere Zahlen als 1, 2 oder 3 eingegeben, soll eine Fehlermeldung erscheinen. Optional kannst du das Programm so anpassen, dass statt der Zahlen die Begriffe „Stein“, „Papier“ und „Schere“ eingegeben werden können.
