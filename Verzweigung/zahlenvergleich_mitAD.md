# Zahlenvergleichen


### Schwierigkeit: *




1. Schreiben Sie ein Programm, bei dem der Nutzer nacheinander eine Ganzzahl eingibt. danach werden die Zahlen miteinander verglichen. Wenn die erste Zahl größer ist als die zweite Zahl so wird "Die erste Zahl ist größer" ausgegeben. Sollte sie kleiner sein wird "Die zweite Zahl ist größer" ausgegeben. Sind beide Zahlen gleich groß so wird "Beide Zahlen sind gleich ausgegeben".
2. Zeichnen Sie zur Aufgabe ein passende UML-Akivitätsdiagramm.
