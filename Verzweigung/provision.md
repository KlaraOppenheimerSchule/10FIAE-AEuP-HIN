# Provision

### Schwiergkeitsgrad: **

Ein Betrieb zahlt seinen Außendienstmitarbeitern neben einem Grundgehalt (Fixum) eine umsatzabhängige Provision:

•	bei einem Umsatz bis 100.000 € = 2 % Provision
•	bei einem Umsatz bis 500.000 € = 3 % Provision
•	bei einem Umsatz von mehr als 500.000 € = 5 % Provision

Schreiben Sie ein Programm welches die Anforderungen umsetzt.

(Test: Umsatz 95.000,00 Euro, Fixum 3.000,00 Euro = 4.900,00 Euro Gesamtgehalt)
