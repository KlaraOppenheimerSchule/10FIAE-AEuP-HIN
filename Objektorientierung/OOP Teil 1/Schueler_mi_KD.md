# Schüler


### Schwierigkeistgrad: **


1. Schreiben Sie in einer objektorientierten Programmiersprache eine Klasse Schüler. Diese hat die Eigenschaften Name, Alter, Mail und Klasse. Für jedes Attribut gibt es eine Get-Methode. Zusätzlich sind für die Attribute Mail und Klasse je eine Set-Methode zu programmieren.
2. Erzeugen Sie nun ein Objekt der Klasse Schüler.
3. Implementieren Sie nun noch zusätzlich die Methode „pruefeVolljaehrig“. Diese soll, wenn der Schüler / die Schülerin volljährig ist, TRUE zurückliefern. Ansonsten FALSE.
4. Nehmen Sie nun noch weitere Ergänzungen vor:
    - Es soll eine Liste an Fächern gespeichert werden. Es können jederzeit Fächer hinzugefügt werden. Selbstverständlich sollen alle Fächer auch abgefragt werden können.
    - Stellen Sie sicher, dass es keine doppelten Fä-cher gibt.Stellen Sie auch die Möglichkeit zur Verfügung, dass Fächer gelöscht werden können.
    - Alle Fächer, welche gespeichert sind, können auch ausgeben werden

5. Erstellen Sie auf Grundlage Ihres Codes eine UML-Klasse.
