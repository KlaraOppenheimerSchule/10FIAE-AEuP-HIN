**Erweitern Sie die Aufgabe Server wie folgt:**


- Erstellen Sie eine Klasse Datenbank mit den Attributen Datenbankname,User, Passwort, IP, Port
- In der Klasse Datenbankserver soll es eine Methode geben, die eine neue Datenbank erzeugt und diese einem neuen Attribut (db) in der Klasse Da-tenbankserver hinzufügt (Objektreferenz).
- Die Klasse Datenbankserver erhält die IP 127.0.0.1 und den Port 3306.
- Datenbankname, User und Passwort werden der Methode zur Erzeugung der Datenbank in der Klasse Datenbankserver übergeben.
- Schreiben Sie zudem eine Methode, die alle Datenbanken des Datenbank-servers zurückgibt mit Datenbankname.
