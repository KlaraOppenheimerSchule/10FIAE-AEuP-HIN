# Server

### Schwierigkeitsgrad: *

Es soll ein Programm entwickelt werden, welches nachstehende Vererbungshierarchie abbildet:
- Es gibt verschiedene Server (Proxyserver und Datenbankserver).
- Alle Server haben einen Namen und die Größenangabe vom Hauptspeicher.
- Proxyserver haben zusätzlich noch ein Protokoll.
- Datenbankserver besitzen eine Angabe über das Datenbankmanagement-system (DBMS).
- Alle Attribute sind von außen nicht sichtbar – außer in der Vererbungshierar-chie – und besitzen Get-Methoden.

1. Erstellen Sie auf Basis der Angaben zunächst ein vollständiges UML-Klassendiagramm.
2. Setzen Sie Ihr Diagramm in einer objektorientierten Programmiersprache Ihrer Wahl um.
